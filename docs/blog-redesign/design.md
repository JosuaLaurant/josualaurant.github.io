# 블로그 디자인 결정 기록

> 상태: 적용 중 · 최초 작성일: 2026-07-21 · 마지막 갱신: 2026-07-21

화면 구현이 따라야 할 유일한 디자인 계약은 [`site/DESIGN.md`](../../site/DESIGN.md)다. 이 문서는 토큰을
복제하지 않고, 왜 이 블로그가 그 규칙을 선택했는지와 이후 바뀐 결정을 기록한다.

## 방향

이 블로그는 만들고, 측정하고, 다시 고치는 과정을 검증 가능한 기술 기록으로 남긴다. 따라서 제품
소개 페이지처럼 많은 CTA·카드·장식 이미지를 쌓지 않고, 긴 한글 본문·코드·측정 결과를 편하게 읽는
에디토리얼 노트로 설계한다.

- 따뜻한 종이색과 절제된 인디고를 쓰되, 보라색 glow나 메쉬 배경으로 기술 블로그의 내용을 장식하지
  않는다.
- 모든 글에 커버 이미지를 강제하지 않는다. 실제 비교에 도움이 될 때만 합성 fixture, 다이어그램,
  측정 표를 넣는다.
- 한글 서체와 시스템 글꼴을 우선해 외부 폰트 요청 없이도 읽기 흐름을 보장한다.
- home의 eyebrow와 섹션 label은 생략하고, 제목·구분선·여백으로 위계를 해결한다.

## 2026-07-21 정합성 결정

루피 검토에서 나온 의견 중 다음만 채택했다.

| 결정 | 이유 |
| --- | --- |
| `site/DESIGN.md`를 구현 계약으로 추가 | 문서와 CSS의 색상·radius·모션 규칙이 서로 어긋나지 않게 한다. |
| reduced motion을 실제 CSS에 적용 | smooth scroll과 카드 hover가 사용자 설정을 존중하게 한다. |
| 강제 줄바꿈을 display copy에만 허용 | home·소개·404의 의도적인 두 줄 제목은 유지하되, 동적 글 제목에는 쓰지 않는다. |
| PostCard의 제목과 태그 링크를 분리 | 카드 전체 링크 규칙이 nested link를 유도하지 않게 한다. |
| 텍스트 우선·무커버 글 허용 유지 | 모든 화면에 이미지를 강제하는 일반적인 anti-slop 규칙은 이 블로그의 목적과 맞지 않는다. |

전면 spacing refactor, 다크 모드, UI 라이브러리, webfont 다운로드는 실제 글과 화면이 늘어난 뒤 별도
결정으로 보류한다.

## 2026-07-21 Apple 인터랙션 원칙의 선택적 반영

Apple식 인터랙션 원칙을 시각 스타일로 복제하지 않고, 읽기 중심 블로그에 직접 도움이 되는 기준만
`site/DESIGN.md`와 화면에 반영했다.

| 채택 | 실제 반영 |
| --- | --- |
| 크기별 타이포그래피 | 시스템 글꼴의 optical sizing을 유지하고 navigation·메타의 자간을 제목·본문과 분리했다. |
| 직접적인 wayfinding | home의 `첫 기록 읽기`를 실제 목적에 맞는 `최근 글 보기`로 바꾸고, 글 카드의 내부 링크 표시는 `→`로 통일했다. |
| 즉각적인 press feedback | header, 홈의 주제·태그 카드, 글 카드 링크가 pointer down에서 색상·표면·경계로 즉시 반응한다. |
| 요약의 출처 표시 | AI가 쓴 description에는 카드와 글 머리말에서 `✦ AI 요약`을 표시하고, 원문의 작성 방식과 요약의 출처를 혼동하지 않는다. |

드래그 물리, 관성·spring, sheet·carousel, glass blur는 현재 정적 블로그에 조작 목적이 없고 읽기 흐름을
해칠 수 있어 채택하지 않는다. hover는 보조 피드백으로만 유지하며, 키보드 focus와 reduced motion 규칙은
기존 계약을 보존한다.
