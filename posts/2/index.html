Hugo로 블로그 만들기

Saturday, Mar 22, 2025 | 3 minute read | Updated at Saturday, Mar 22, 2025

들어가면서

사실 현재 보이는 결과물 이전에 사실 수차례의 블로그를 만드려는 시도가 있었다.
당장 초등학생 때부터 다음이나 네이버 블로그를 사용하고 있었지만
개발을 시작하면서 특정 사이트의 블로그가 아니라 직접 만든 블로그를 써보고 싶었고
어떤 방식으로 / 어떻게 관리할 것인지 엄청나게 고민했었다.

실제로 첫 시도를 했던 건 아마 16년인데 (github에 16년도에 지킬이 어쩌구 하는 repository가 있음)
정작 현재 이 글이 작성되고 있는 Hugo와 Github Pages를 이용한 블로그가 세상 밖으로 나온 첫 블로그다…

매번 고민하면서 어떤 기술을 사용할 지 고민하다가 그만두기를 반복하다가
현재 준비하고 있는 지원서와 포트폴리오가 있어 Spring을 이용한 프로젝트가 급하게 필요하게 되었다.

블로그 제작을 고민하다가 결국엔 기록할 내용들을 노션에만 정리했었는데 이렇게 몇 년 간 노션에 정리하다보니
페이지가 너무 많아지고 구조가 복잡해지면서 이번에는 진짜 블로그로 옮겨야지 하던 차에 앞의 글에서 썼듯이
미니PC가 생기게 되었고 블로그 제작이 메인이 아니라 다른 프로젝트를 하기 전에 사전 작업의 느낌으로 블로그 제작에 대한 수요가 생기다보니 급한대로라도 결과물이 나오게 되었다.

Hugo로 블로그 만들기

위의 이유로 이번에는 블로그 구조 자체에는 신경을 많이 쓰고 싶지 않았다.
블로그를 만들면 여러 개를 파서 여행 사진들을 정리해서 올릴 블로그도 같이 필요했다보니 이미지를 내 서버에 두고 대용량 업로드가 가능해야되는 등 여러 필요한 조건이 많았는데 이번엔 일단 글로 된 포스트만 빠르게 올리는 것이 메인이다보니 일단 Github Pages를 사용하게 되었다.

페이지 생성?에는 사람들이 많이 사용하는 건 Jekyll과 Hugo가 일단 보였다.

Jekyll의 경우 Ruby를 사용하고 Hugo는 Go를 사용하는데 뭐 당분간 직ㅈ버 ruby나 go를 이용하지는 않겠지만 만약 쓰게 된다면 Go를 이용하는게 앞으로 더 도움이 될 것 같다는 판단으로 일단 Hugo를 사용해 보게 되었다.

일단 Hugo를 설치 후, 생성된 프로젝트 폴더를 git으로 관리하도록 했다.

Hugo new site blog1로 blog1 폴더를 만들고 해당 폴더에 git init을 했다.

원래 new로 폴더를 생성하면 root 폴더에 config.toml 파일이 있다고 했는데 내 경우는 config가 생성되지 않아 직접 config 파일을 작성해 주었다.

baseURL = 'https://josualaurant.github.io/'
languageCode = 'en-us'
title = '개발 블로그'
paginate = 10

Hugo의 경우 https://themes.gohugo.io/ 에서 테마를 골라 적용할 수 있는데 일단 적당히 깔끔해 보이는 아무 테마를 다운받아서 설정하였다.
설정 후, 다시 config 파일안에 theme = "hugo-theme-m10c" 와 같이 한 줄 추가해 주고

Hugo server -D 를 입력하면 localhost에서 블로그가 어떻게 보이는 지 확인할 수 있다. (기본 포트:1313)

포스트는 hugo new posts/1.md 를 입력하면 제목이 1인 글을 등록하는 MarkDown 문서가 만들어진다.

이제 실제로 github.io에 올리기 위해 hudo -D로 블로그를 빌드할 수 있다.

앞에서부터 사용했던 -D 플래그는 Draft 중인 포스트도 포함해서 보기/빌드하는 플래그다.

이렇게 빌드를 하면 public 폴더 내에 html 파일 등이 생성된다. github에 ~~.github.io로 끝나는 블로그 주소로 사용할 이름으로 프로젝트를 만들고 이 public 폴더를 git에 연결하면 이제 ~~.github.io에서 포스트한 글들을 볼 수 있다.

프로젝트에서 Settings로 들어가면 어떤 브랜치를 github 블로그로 쓸 수 있는지도 설정할 수 있다.

테스트 결과

josualaurant.github.io에서 블로그 글들이 잘 뜨는 건 확인했는데 원하던 것보다 가로 사이즈가 작아서 테마를 바꿔야 될 것 같다.

하지만 필요한 다른 작업들이 있어서 일단 글을 쓰고 볼 수 있는 것에 만족하고 당분간은 이대로 쓰는 걸로…

참고로 테마 변경은 그냥 themes 폴더에 원하는 폴더를 체크아웃 받고 빌드할 때 -t ~~theme 플래그를 넣어서 바꿔주면 그만
