## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Design

Before changing UI, CSS, layout, or visible content structure, read `DESIGN.md`. It is the canonical design
contract for this site; do not import or apply Atelier's separate `DESIGN.md`.
