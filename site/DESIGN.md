# Josua Laurant 기술 기록 디자인 계약

> 상태: v2 적용 중 · 적용 범위: `site/`

이 문서는 이 Astro 사이트의 화면 구현 기준이다. 새 색상·서체 크기·spacing·radius·motion 값이 필요하면
먼저 여기에 의미와 값을 추가한 뒤 CSS에 사용한다. 이전 설계의 배경과 결정 기록은
[`../docs/blog-redesign/design.md`](../docs/blog-redesign/design.md)에 둔다.

## 1. 분위기와 서명

작업 책상 위에 펼친 엔지니어링 노트. 나뭇결 책상 위에 스프링 줄 노트를 펼쳐 두고, 홈은 노트 앞쪽의 목차
페이지, 글은 번호가 매겨진 노트 한 장이다. 주제와 목차는 포스트잇으로, 빈 책상에는 커피잔·연필·클립 같은
소품을 둔다. 소품은 장면을 만드는 장식이고, 읽기와 탐색은 노트와 포스트잇만으로 완결돼야 한다.

보라색 glow, 다크 메쉬, 글래스 blur, 과도한 카드와 CTA는 쓰지 않는다. 사실적인 질감(나뭇결·종이 겹침·
테이프)과 그림자는 책상 장면을 만드는 데만 쓴다.

`--canvas`·`--surface`는 `--paper`를, `--line`·`--line-strong`은 종이 경계 계열을 가리키는 호환 이름이다.
대비: 종이 위 `--ink` 15.2:1(다크 12.3:1), `--ink-muted` 6.2:1(6.5:1), `--pen-red` 4.8:1(6.4:1),
`--accent-deep` 8.0:1(8.2:1). 책상 위 `--desk-ink`는 8.2:1(11.1:1), 포스트잇 위 `--note-ink`는 7:1 이상이다.
색상만으로 링크·현재 상태·의미를 구분하지 않는다.

기본값은 시스템 설정(`prefers-color-scheme`)을 따른다. 헤더의 테마 버튼으로 바꾸면 `html[data-theme]`과
`localStorage`의 `theme`에 저장하고, `<head>`의 inline script가 첫 paint 전에 복원한다. 다크는 밤의 월넛
책상과 스탠드 불빛이다.

## 3. 타이포그래피와 줄

- 기본 글꼴: `Pretendard`, `Apple SD Gothic Neo`, 시스템 sans-serif. 웹폰트를 별도 내려받지 않는다.
- 숫자·날짜·번호·버전은 `.mono`(시스템 monospace, 한글은 Pretendard로 대체, `word-spacing: -0.25em`)로 쓴다.
- 공책 줄 간격 `--rule-gap`은 `2rem`이다. 줄 위에 놓이는 글자는 줄 높이를 이 값이나 그 배수로 둔다.
  - 페이지 제목(홈·목록): `clamp(1.9rem, 4.5vw, 2.8rem)` / 800 / 줄 높이 `4rem` / `-0.05em`
  - 글 제목: `clamp(1.8rem, 4.5vw, 2.6rem)` / 800 / `3rem` / `-0.05em`(줄 없는 머리 영역)
  - 본문: `1.04rem` / 400 / `2rem`. 문단 사이는 한 줄을 비운다.
  - 본문 소제목 h2: `clamp(1.3rem, 3vw, 1.55rem)` / 파란 펜 / `2rem`, 위로 두 줄을 비운다.
- 글 머리(기입란·제목·설명·출처·태그)는 줄 없는 영역이고, 본문(`.post-body.ruled`)부터 줄이 시작한다.
- 코드 블록·표·이미지처럼 높이를 줄에 맞출 수 없는 블록은 PostLayout의 snap script가 아래 여백을 늘려 다음
  줄을 다시 맞춘다. 스크립트가 없어도 읽기에는 지장이 없다.
- label·eyebrow: `0.72rem` / 800 / `0.04em`. 라벨은 한국어로 쓴다.

긴 동적 제목은 자연스럽게 줄바꿈한다. `<br>`은 소개·404의 고정 문구에서만 허용한다. 사용자에게 보이는
제목에는 em dash를 쓰지 않는다. 한글은 제목·본문·메타 모두 단어 안에서 끊지 않는다(`body`의
`word-break: keep-all`). 화면보다 긴 URL·식별자만 예외로 줄바꿈한다.

## 4. 레이아웃

| 역할 | CSS 변수 | 값 |
| --- | --- | --- |
| 노트 폭 | `--sheet-max` | `46rem` (안쪽 글 폭 약 38~40rem, 한 줄 한글 약 38자) |
| 공통 폭 | `--shell-max` | `76rem` |
| 반응형 좌우 여백 | `--shell-padding` | `clamp(1.15rem, 4vw, 2.5rem)` |

- `DeskLayout`: 78rem 이상에서는 `1fr | 노트 | 1fr` 세 열로 노트를 가운데, 포스트잇을 오른쪽 열에 둔다. 더
  좁으면 포스트잇이 노트 아래로 내려가 두 장씩 놓인다.
- 소품(`Desk`)은 88rem 이상에서만 노트 왼쪽 빈 책상에 보인다. 오른쪽 책상은 포스트잇 자리이며, 소품이 노트·포스트잇을
  가리지 않는다.
- 노트 안 여백: 위 `3rem`(스프링 자리), 왼쪽은 여백선 오른쪽 `clamp(2.9rem, 8vw, 5.2rem)`.

## 5. 컴포넌트

- `NotebookSheet`: 종이 한 장. 위쪽 스프링(`/desk/spiral.svg`), 왼쪽 빨간 여백선, 아래로 겹친 장 세 겹과 그림자.
  오른쪽 가장자리에 클립 하나를 물린다(40rem 이하에서는 숨김). `pageLabel`이 있으면 오른쪽 아래에 `— No.002 —`처럼 쪽 번호를 찍는다.
- `IndexList`: 목차 줄. `No.003`(빨간 펜) · 제목 · 날짜, 다음 줄에 `주제 · ✦ AI 작성 — 설명`. 홈·전체 글·주제·
  태그 목록이 함께 쓴다. 글 번호는 공개 글을 오래된 순으로 센 값이다.
- `StickyNote`: 포스트잇. 색 네 가지와 기울기, 위쪽 마스킹테이프. 링크면 hover에서 똑바로 서며 살짝 뜬다.
- `CategoryNotes`: 주제마다 포스트잇 한 장과 `모든 주제·태그` 한 장.
- 글 머리 기입란: `주제 | 날짜 | 번호` 세 칸 표. 파란 펜 테두리, 좁은 화면에서는 번호 칸이 아래로 내려간다.
- 글 목차: 78rem 이상에서는 오른쪽 노란 포스트잇이 스크롤을 따라오고, 좁으면 노트 안 점선 상자다.
- 고친 기록: `revisions`가 있는 글은 본문 뒤에 빨간 펜(`--pen-red`) 점선으로 나눈 `고친 기록`을 최신순으로
  붙이고 `처음 씀`으로 끝낸 뒤 GitHub 원고 변경 내역으로 잇는다. 글 머리의 `(고침 날짜)`는 이 기록으로 가는 링크다.
- 글 끝: `← 이전 장` / `다음 장 →` 링크와 `전체 글 목록 · <주제>의 다른 글`, 그 뒤에 댓글.
- Header·Footer: 책상 위에 직접 놓인 글자다. 탐색은 `글`·`주제`·`소개`·`업데이트`, 현재 구역은
  `aria-current`와 굵기로 표시한다. 테마 버튼은 종이색 원형 버튼이다.
- 주제 페이지: 노트 안에 주제 포스트잇과 마스킹테이프 모양 태그 라벨을 붙인다.
- Provenance: 본문 작성자(`writing`)를 우선해, 목록에는 `✦ AI 작성`만, 글 머리말에는 본문과 요약을 누가
  썼는지 한 문장으로 밝힌다.
- Comments: giscus를 노트 안 글 끝에 lazy load한다. `public/giscus/{light,dark}.css`가 종이 토큰으로 덮어쓰고
  사이트 테마를 따라간다.

## 6. 책상 소품과 변주

`Desk`의 소품은 모두 inline SVG이고 `aria-hidden`이다. `BaseLayout`의 head script가 첫 paint 전에 `html`의
`data-*` 속성을 정하고, CSS 변수와 표시 여부가 그 값을 따른다. 스크립트가 없으면 흰 잔·노란 연필 기본값이다.

| 속성 | 값 | 정하는 방식 |
| --- | --- | --- |
| `data-mug` | `white` `navy` `terracotta` `mint` | 방문마다 무작위 |
| `data-pencil` | `yellow` `red` `green` `blue` | 방문마다 무작위 |
| `data-writer` | `pencil`(75%) `pen` | 방문마다 무작위 |
| `data-stain` | `on`(60%) `off` | 컵 자국 |
| `data-layout` | `a` `b` `c` | 잔·연필·이스터에그 위치 묶음 |
| `data-drink` | `coffee` / `tea`(23~5시) / `double`(월요일, 잔 두 개) | 방문자 시각 |
| `data-egg` | `xmas`(12/24~26) `newyear`(1/1) `halloween`(10/31) `birthday`(7/21) `cat`(그 외 3%) `none` | 방문자 날짜 |

확인용으로 `?desk-egg=<값>`·`?desk-drink=<값>`을 주면 해당 값을 강제한다. 소품 종류 자체를 바꾸지 않고 색·
배치·작은 물건만 바꾼다. 새 이스터에그는 왼쪽 책상의 `--egg-top` 자리를 쓰고, 세 배치에서 잔·연필과
겹치지 않는지 확인한다.

## 7. 상호작용과 모션

- 공통 focus: `3px` 파란 펜 outline과 `3px` offset.
- press feedback: 링크와 포스트잇은 pointer down에서 즉시 색·위치로 반응한다.
- 포스트잇 hover: 기울기를 풀고 `translateY(-3px)`, `160ms ease`.
- `prefers-reduced-motion: reduce`에서는 smooth scroll과 포스트잇 transition을 끈다.
- hover는 보조 피드백이다. 읽기와 탐색은 터치·키보드만으로 완결돼야 한다.

## 8. 시각 자료와 새 화면 확인

- 코드 블록은 Shiki 토큰 색을 쓰되 배경은 `--code-surface`로 덮는다.
- 새 글의 작성과 포스팅은 AI가 진행한다. 검증할 수 없는 수치·사실·측정 조건은 글에 넣지 않는다.
- 공개 자료에는 권한 없는 원본 자료, private 데이터, prompt, 내부 경로·호스트·token을 넣지 않는다.
- 새 화면은 `npm run check`, `npm run build` 뒤 라이트·다크 × 390·768·1280·1440px에서 줄 정렬, 긴 한글
  제목, 코드, focus, 가로 overflow, 소품 겹침을 실제로 확인한다.
